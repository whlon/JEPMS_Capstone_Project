# JEPMS – Job & Employability Progression Management System

A secure web application for employment advisers to record and manage job application information. Built as a Level 3 capstone project.

## Purpose
Staff currently keep vacancies and job applications in separate spreadsheets.
JEPMS gives them one searchable place to add, view, edit and delete
application records, and offers the same data to other programs through an API.

## Planned technology stack
- Python 3
- Django (website, login, admin, forms)
- FastAPI (JSON API with automatic documentation)
- SQLite (database)
- Bootstrap (page styling)
- Git and GitHub (source control and planning)
- PythonAnywhere (deployment)
